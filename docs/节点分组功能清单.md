# 节点分组功能清单

| 功能区域 | 功能 | 子级功能 | 功能描述 | 功能截图 |
| --- | --- | --- | --- | --- |
| 画布选择 | 左键框选 | 相交选中 | 在画布空白处按住左键拖拽，所有与选框相交的节点进入选中状态。 | 【截图占位】 |
| 画布选择 | 左键框选 | 持续选区外框 | 松开鼠标后，选区外框持续显示，精确覆盖所选节点的最上、下、左、右边缘，不额外加留白。 | 【截图占位】 |
| 画布选择 | 多选 | Shift 叠加 | 按住 Shift 框选或点击节点时，在已有选择基础上增加节点；普通框选会替换原选择。 | 【截图占位】 |
| 画布选择 | 多选 | 同步移动 | 拖动任一已选节点时，当前所有已选节点按相同位移移动，连线继续跟随节点端点。 | 【截图占位】 |
| 画布选择 | 选区工具条 | 屏幕固定 | 选区上方显示不随画布缩放的浮动工具条，并限制在当前视口内，避免被画布边缘截断。 | 【截图占位】 |
| 画布选择 | 选区工具条 | 批量下载 | 下载选中节点当前激活的图片、视频或音频内容；相同 URL 只下载一次，并在结束后提示成功和失败数量。 | 【截图占位】 |
| 画布选择 | 选区工具条 | 打组 | 选择至少两个节点后可点击“打组”，也可使用 Ctrl/Cmd+G。 | 【截图占位】 |
| 节点分组 | 语义组 | 数据模型 | 组保存标题、成员节点 ID、布局状态和创建时间；成员节点仍使用原有世界坐标，不迁移到局部坐标。 | 【截图占位】 |
| 节点分组 | 语义组 | 视觉容器 | 组外框由成员节点位置实时派生，包含顶部标题区和内容内边距；成员移动、缩放后外框自动更新。 | 【截图占位】 |
| 节点分组 | 语义组 | 成员约束 | 首版不支持嵌套组或一个节点属于多个组。重新打组会从原组移出节点；不足两个成员的旧组自动移除。 | 【截图占位】 |
| 节点分组 | 整体移动 | 拖动组标题 | 拖动组顶部标题即可整体移动全部成员节点，所有节点使用同一世界坐标位移。 | 【截图占位】 |
| 节点分组 | 组内编辑 | 双击进入 | 双击组标题进入组内编辑提示状态；此时可直接选择、拖动和调整任一成员节点，操作规则与普通画布一致。按 Esc 退出该状态。 | 【截图占位】 |
| 节点分组 | 组内编辑 | 边界自适应 | 单独移动、调整尺寸或删除成员后，组容器边界随剩余成员自动计算。 | 【截图占位】 |
| 节点分组 | 组工具条 | 宫格整理 | 选中组后提供“整理”。按成员原有视觉顺序（先 y、后 x、再原数组顺序）排成宫格，最多四列。 | 【截图占位】 |
| 节点分组 | 组工具条 | 异形节点布局 | 宫格列宽取该列最宽节点、行高取该行最高节点，节点在格子内居中，节点自身尺寸不改变。 | 【截图占位】 |
| 节点分组 | 组工具条 | 组内批量下载 | 选中组后可下载其成员的当前激活内容；按稳定阅读顺序编号，URL 去重并提示结果。 | 【截图占位】 |
| 节点分组 | 组工具条 | 解组 | 选中组后点击“解组”，或按 Ctrl/Cmd+Shift+G，移除组容器但保留成员节点和连线。 | 【截图占位】 |
| 数据与历史 | 本地持久化 | 子画布快照 | `groups` 与节点、连线、画布变换一起写入当前子画布本地快照；旧快照缺少 `groups` 时按空数组兼容。 | 【截图占位】 |
| 数据与历史 | 项目与工作流 | 保存及导入导出 | 项目本地保存、`.flow/.json` 导入和导出均携带 `groups`；导入时清理不存在的节点引用和无效组。 | 【截图占位】 |
| 数据与历史 | 复制与删除 | 复制完整组 | 复制选中节点时，若完整包含某个组的全部成员，会连同该组一并复制；内部连线映射到新节点。 | 【截图占位】 |
| 数据与历史 | 复制与删除 | 删除成员 | 删除节点会同步从其所属组移除；不足两个成员时组自动移除，避免孤立引用。 | 【截图占位】 |
| 数据与历史 | 撤销 | 分组操作 | 打组、解组和宫格整理进入现有撤销历史；删除节点撤销时同时恢复删除前的分组引用。 | 【截图占位】 |
| 交互保护 | 快捷键 | 输入区域保护 | input、textarea、select 和 contenteditable 内不响应打组、解组、删除、对齐等画布级快捷键。 | 【截图占位】 |
