# 参考图人物识别交付说明

本次实现：**一次读图同时识别场景 / 道具 / 人物**，人物按真实比例（不与家具一样大）创建为可编辑的角色占位对象。

## 怎么用

1. 打开导演台 → 场景面板 →「参考图粗布景」，给一张参考图。
2. 生成后，暂存预览里会出现两块：
   - **布景组件**（地面 / 墙 / 门窗 / 桌椅沙发柜）
   - **人物**（姿态 + 身高 + 面朝 + 置信度）
3. 人物可以：改名称、改身高（0.5–2.5 米）、切姿态（站 / 坐 / 蹲 / 跪 / 卧 / 未知）、改面朝角度、删除。
4. 「添加到当前场景」后，人物变成**和手动添加完全同权**的角色对象——能摆位、改姿态、排走位、拍跟拍。

## 比例是怎么保证的（三层）

| 层 | 做法 |
|---|---|
| Prompt | 强制模型「以图中站立成年人 1.7 米为整图比例尺」，人和家具同一把尺 |
| 校准 | 锚定「沙发宽 2 米」后，人物与布景乘同一因子，相对比例守恒 |
| 应用 | 按 `身高 ÷ 素体原生高 1.86 米` 换算模型缩放，哪怕草稿整体尺度估偏，人物身高仍是绝对米制 |

坐姿人物的 Y 是**座面高度**（约 0.45），不是地面，所以角色会自然「坐」在沙发上；「整批贴地」会跳过人物，不会把坐着的人拉到地板上。
